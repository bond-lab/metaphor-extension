  The literature strongly supports metonymy as the correct analysis. The key arguments:

  For metonymy (dominant position):

  1. Casson (1994) — your starting point — is explicit: "Entity stands for entity's color" is ontological metonymy. His lemon example is the clearest
  illustration: the color sense is metonymic (the fruit's salient perceptual property), while the "defective thing" sense is metaphorical. These are different
  kinds of extension and should not be collapsed.
  2. Radden & Kövecses (1998) define metonymy as one entity providing mental access to another within the same Idealized Cognitive Model (ICM). The color is a
  characteristic property of the entity — it's within the same experiential frame, not a separate domain. This is their CHARACTERISTIC PROPERTY FOR ENTITY
  pattern (or its inverse).
  3. Barcelona (2003) and subsequent work identify ENTITY STANDS FOR CHARACTERISTIC as a core metonymy type. Color is prototypically characteristic of
  plants/minerals — we identify lemons as yellow, roses as pink. The color is definitionally tied to the entity, not imported from a separate conceptual
  domain.
  4. Cognitive primacy: metonymy is generally considered to be cognitively more basic and historically prior to metaphor. For color naming, the standard
  account is that entity → color naming is metonymic in origin, with some items later developing further metaphorical extensions (e.g., "red" → revolutionary,
  "green" → inexperienced).
  5. Hamilton (2016), a PhD thesis specifically on figurative color in English, argues that figurative color uses originate through metonymy and are
  subsequently extended into metaphor — "from metonymy to metaphor."

  For metaphor (minority/no strong advocates found):

  The only coherent argument for metaphor would be that the color domain and the physical entity domain are conceptually distinct enough to count as
  cross-domain mapping. But this is hard to sustain: the color IS a perceptual property of the entity; calling a fruit's characteristic color a "cross-domain"
  extension seems theoretically unmotivated. No prominent cognitive linguist appears to argue this position for the basic ENTITY → COLOR naming case.
